# Results folder

This starter package contains two **reference runs generated from the included code**:
- `python_reference/`: 200,000 bits per modulation/EbN0 point, Python NumPy implementation.
- `cpp_reference/`: 1,000,000 BPSK bits per Eb/N0 point, C++17 implementation.

These are reproducibility examples, not measurements from Omar's own MATLAB/Simulink installation. Run the programs on your laptop and compare the outputs. Keep every result tied to its software version, random seed, modulation, Eb/N0 range, and tested bit count. Do not use these starter outputs as evidence of a MATLAB/Simulink run.
